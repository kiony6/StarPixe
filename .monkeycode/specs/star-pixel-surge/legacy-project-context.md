## ✅ 核心功能清单

### 1. 战斗系统
- 自动技能释放（无需玩家点击，隐藏技能图标UI）
- 6大类技能特效：分裂弹幕、穿透弹、追踪弹、多目标锁定激光；25技能树，24套组合技能
- Boss阶段机制：狂暴转阶段、子弹雨，Boss全玩家画面同步；多人共享经验，个人技能独立
- 词缀系统：攻击加成、冷却缩减、多重投射；拾取词缀顶部提示+图标双动画反馈

### 2. 联机网络（Netcode + Relay + Lobby + Vivox）
- 大厅：公开房间 / 密码房间；房间标签【等待中/游戏中】，开局锁房禁止新玩家进入
- 房主权限：踢人、锁房间；主机迁移（房主掉线自动转移主机，迁移弹窗提示）
- 聊天：消息颜色区分房主/普通玩家/系统提示；内置Vivox小队语音，带扬声器开关
- 断线重连；多人画面特效完全同步，全局Boss实例统一

### 3. UI & 视觉（霓虹风格）
- 主菜单（昵称登录）、对局ESC暂停面板（放弃本局确认弹窗）、结算界面
- HUD：Boss血条、连杀飘分、拾取提示条、技能CD图标发光提醒
- UiFactory工具：霓虹描边、外发光，整套UI动态特效；程序化渲染，怪物/弹幕/BOSS自动配色

### 4. 地图与波次
- 随机房间程序化地图生成；怪物波次系统

### 5. 附加模块
- 排行榜、本地技能树存档
- 音效系统：按钮点击、技能释放AudioSource

### 6. 美术管线
- 资源目录规范 `Assets/11_Res/Resources/Sprites/`，贴图自动批量导入配置
